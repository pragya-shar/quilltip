# Convex backend

Run commands from the repository root with Bun. For local deployment selection,
auth, environment variables, and startup behavior, read [setup](../docs/SETUP.md).
For production operations, read [deployment](../docs/DEPLOYMENT.md).

- `schema.ts` defines application data; `auth.ts` and `auth.config.ts` configure
  Convex Auth. Inspect each function's identity and ownership checks before edits.
- `crons.ts` lists scheduled recovery, reconciliation, cleanup, and price jobs.
- `_generated/` is generated by Convex; regenerate it through the CLI when needed.
- `bun run dev:backend` pushes/watches the configured development backend. Confirm
  the target first, particularly when sharing a backend across local checkouts.

Use the [Convex function documentation](https://docs.convex.dev/functions) for API
syntax rather than maintaining example functions in this file.
